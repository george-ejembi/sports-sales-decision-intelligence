## 1. Purpose

This document contains the centralized DAX measure layer for the Sports Sales Decision Intelligence Power BI solution.

The measures are designed to support:

- Revenue performance
- Sales volume analysis
- Operating profitability
- Time intelligence
- Product intelligence
- Retailer analysis
- Sales-method analysis
- Geographic performance
- Revenue-to-profit risk
- Commercial opportunity identification
- Management decision-making

## 3. Core Business Measures

### 3.1 Total Sales

```dax
Total Sales =
SUM('Sales'[Total Sales])
```
Measures total revenue generated by the business.

### 3.2 Total Operating Profit

```dax
Total Operating Profit =
SUM('Sales'[Operating Profit])
```
Measures total operating profit generated.

### 3.3 Total Units Sold

```dax
Total Units Sold =
SUM('Sales'[Units Sold])
```
Measures total product volume sold.

### 3.4 Active Retailers

```dax
Active Retailers =
DISTINCTCOUNT('Sales'[Retailer ID])
```
Measures the number of unique retailers contributing sales.

## 4. Profitability Measures

### 4.1 Operating Margin %

```dax
Operating Margin % =
DIVIDE(
    [Total Operating Profit],
    [Total Sales],
    0
)
```
Measures the proportion of revenue converted into operating profit.

### 4.2 Profit per Unit

```dax
Profit per Unit =
DIVIDE(
    [Total Operating Profit],
    [Total Units Sold],
    0
)
```
Measures average operating profit generated per unit sold.

### 4.3 Sales per Unit

```dax
Sales per Unit =
DIVIDE(
    [Total Sales],
    [Total Units Sold],
    0
)
```
Measures average revenue generated per unit.

### 4.4 Product Profitability Index

```dax
Product Profitability Index =
DIVIDE(
    [Total Operating Profit],
    [Total Sales],
    0
)
```
Measures profitability relative to sales.

> **Note:** At the product level this effectively represents the product's operating margin.

### 4.5 Commercial Efficiency Index

```dax
Commercial Efficiency Index =
DIVIDE(
    [Total Operating Profit],
    [Total Sales],
    0
) * 100
```
Represents the percentage of sales retained as operating profit. Primarily intended for KPI presentation.

## 6. Time Intelligence

### 6.1 Previous Month Sales

```dax
Previous Month Sales =
CALCULATE(
    [Total Sales],
    PREVIOUSMONTH('Date'[Date])
)
```
Returns sales for the previous month.

### 6.2 Previous Month Profit

```dax
Previous Month Profit =
CALCULATE(
    [Total Operating Profit],
    PREVIOUSMONTH('Date'[Date])
)
```
Returns operating profit for the previous month.

### 6.3 MoM Sales Growth %

```dax
MoM Sales Growth % =
VAR CurrentSales =
    [Total Sales]
VAR PreviousMonthSales =
    CALCULATE(
        [Total Sales],
        PREVIOUSMONTH('Date'[Date])
    )
RETURN
    IF(
        ISBLANK(PreviousMonthSales),
        BLANK(),
        DIVIDE(
            CurrentSales - PreviousMonthSales,
            PreviousMonthSales,
            0
        )
    )
```
Measures month-over-month revenue growth. The first available month intentionally returns blank because there is no previous month for comparison.

### 6.4 MoM Profit Growth %

```dax
MoM Profit Growth % =
VAR CurrentProfit =
    [Total Operating Profit]
VAR PreviousMonthProfit =
    CALCULATE(
        [Total Operating Profit],
        PREVIOUSMONTH('Date'[Date])
    )
RETURN
    IF(
        ISBLANK(PreviousMonthProfit),
        BLANK(),
        DIVIDE(
            CurrentProfit - PreviousMonthProfit,
            PreviousMonthProfit,
            0
        )
    )
```
Measures month-over-month operating profit growth.

### 6.5 Sales Growth %

```dax
Sales Growth % =
VAR CurrentSales =
    [Total Sales]
VAR PreviousSales =
    CALCULATE(
        [Total Sales],
        DATEADD(
            'Date'[Date],
            -1,
            MONTH
        )
    )
RETURN
    IF(
        ISBLANK(PreviousSales),
        BLANK(),
        DIVIDE(
            CurrentSales - PreviousSales,
            PreviousSales,
            0
        )
    )
```
Measures period-over-period sales growth.

### 6.6 Profit Growth %

```dax
Profit Growth % =
VAR CurrentProfit =
    [Total Operating Profit]
VAR PreviousProfit =
    CALCULATE(
        [Total Operating Profit],
        DATEADD(
            'Date'[Date],
            -1,
            MONTH
        )
    )
RETURN
    IF(
        ISBLANK(PreviousProfit),
        BLANK(),
        DIVIDE(
            CurrentProfit - PreviousProfit,
            PreviousProfit,
            0
        )
    )
```
Measures period-over-period profit growth.

### 6.7 MoM Sales Growth Indicator

```dax
MoM Sales Growth Indicator =
VAR CurrentSales =
    [Total Sales]
VAR PreviousMonthSales =
    CALCULATE(
        [Total Sales],
        PREVIOUSMONTH('Date'[Date])
    )
VAR Growth =
    DIVIDE(
        CurrentSales - PreviousMonthSales,
        PreviousMonthSales,
        0
    )
RETURN
    IF(
        ISBLANK(PreviousMonthSales),
        BLANK(),
        IF(
            Growth > 0,
            "↑ " & FORMAT(Growth, "0.0%"),
            IF(
                Growth < 0,
                "↓ " & FORMAT(Growth, "0.0%"),
                "→ " & FORMAT(Growth, "0.0%")
            )
        )
    )
```
Provides a presentation-friendly growth indicator.

## 7. Profitable Growth Intelligence

### 7.1 Profitable Growth Index

```dax
Profitable Growth Index =
VAR SalesGrowth =
    [Sales Growth %]
VAR ProfitGrowth =
    [Profit Growth %]
RETURN
    IF(
        OR(
            ISBLANK(SalesGrowth),
            ISBLANK(ProfitGrowth)
        ),
        BLANK(),
        100
            * (1 + SalesGrowth)
            * (1 + ProfitGrowth)
    )
```
Provides a combined view of sales and profit growth.

**Interpretation**

| Sales | Profit | Interpretation |
|---|---|---|
| ↑ | ↑ | Profitable Growth |
| ↑ | ↓ | Unprofitable Growth |
| ↓ | ↑ | Efficiency Opportunity |
| ↓ | ↓ | Commercial Decline |

### 7.2 Growth Classification

```dax
Growth Classification =
VAR SalesGrowth =
    [Sales Growth %]
VAR ProfitGrowth =
    [Profit Growth %]
RETURN
    SWITCH(
        TRUE(),
        ISBLANK(SalesGrowth)
            || ISBLANK(ProfitGrowth),
            "Insufficient Data",
        SalesGrowth > 0
            && ProfitGrowth > 0,
            "Profitable Growth",
        SalesGrowth > 0
            && ProfitGrowth <= 0,
            "Unprofitable Growth",
        SalesGrowth <= 0
            && ProfitGrowth > 0,
            "Efficiency Opportunity",
        SalesGrowth <= 0
            && ProfitGrowth <= 0,
            "Commercial Decline",
        "Monitor"
    )
```
Used to classify commercial performance into actionable growth states.

## 8. Revenue-to-Profit Risk

### 8.1 Revenue-to-Profit Risk Index

```dax
Revenue-to-Profit Risk Index =
(
    [Sales Contribution %]
    -
    [Profit Contribution %]
) * 100
```

**Interpretation**

- Positive value → sales contribution exceeds profit contribution.
- Near zero → revenue and profit contribution are broadly aligned.
- Negative value → profit contribution exceeds sales contribution.
- A high positive value can indicate a potential revenue quality or margin risk.

### 8.2 Product Revenue-to-Profit Risk

```dax
Product Revenue-to-Profit Risk =
VAR ProductSalesContribution =
    DIVIDE(
        [Total Sales],
        CALCULATE(
            [Total Sales],
            ALLSELECTED('Sales'[Product])
        ),
        0
    )
VAR ProductProfitContribution =
    DIVIDE(
        [Total Operating Profit],
        CALCULATE(
            [Total Operating Profit],
            ALLSELECTED('Sales'[Product])
        ),
        0
    )
RETURN
    ProductSalesContribution
    -
    ProductProfitContribution
```
Measures the difference between a product's revenue contribution and profit contribution within the current selection.

## 9. Profitability Category Measures

### 9.1 Profit Contribution by Category

```dax
Profit Contribution by Category =
DIVIDE(
    [Total Operating Profit],
    CALCULATE(
        [Total Operating Profit],
        ALLSELECTED(
            'Sales'[Profitability Category]
        )
    ),
    0
)
```
Shows how much operating profit each profitability category contributes.

### 9.2 Sales Contribution by Profitability Category

```dax
Sales Contribution by Profitability Category =
DIVIDE(
    [Total Sales],
    CALCULATE(
        [Total Sales],
        ALLSELECTED(
            'Sales'[Profitability Category]
        )
    ),
    0
)
```
Shows the revenue contribution of each profitability category.

### 9.3 Profitability Efficiency Gap

```dax
Profitability Efficiency Gap =
VAR SalesContribution =
    DIVIDE(
        [Total Sales],
        CALCULATE(
            [Total Sales],
            ALLSELECTED(
                'Sales'[Profitability Category]
            )
        ),
        0
    )
VAR ProfitContribution =
    DIVIDE(
        [Total Operating Profit],
        CALCULATE(
            [Total Operating Profit],
            ALLSELECTED(
                'Sales'[Profitability Category]
            )
        ),
        0
    )
RETURN
    (
        ProfitContribution
        -
        SalesContribution
    ) * 100
```

**Interpretation**

| Gap | Meaning |
|---|---|
| Positive | Category generates more profit than revenue contribution |
| Around 0 | Revenue and profit contribution are aligned |
| Negative | Category generates more revenue than profit contribution |

## 10. Product Intelligence

### 10.1 Product Opportunity Score

```dax
Product Opportunity Score =
VAR SalesScore =
    DIVIDE(
        [Total Sales],
        CALCULATE(
            [Total Sales],
            ALLSELECTED('Sales'[Product])
        ),
        0
    )
VAR MarginScore =
    DIVIDE(
        [Product Profitability Index],
        CALCULATE(
            [Product Profitability Index],
            ALLSELECTED('Sales'[Product])
        ),
        0
    )
VAR VolumeScore =
    DIVIDE(
        [Total Units Sold],
        CALCULATE(
            [Total Units Sold],
            ALLSELECTED('Sales'[Product])
        ),
        0
    )
VAR GrowthScore =
    MAX(
        0,
        COALESCE(
            [MoM Sales Growth %],
            0
        )
    )
RETURN
    (
        SalesScore * 25
    )
    +
    (
        MarginScore * 30
    )
    +
    (
        VolumeScore * 20
    )
    +
    (
        GrowthScore * 25
    )
```

> **Important:** This is a relative composite score, not a statistically validated probability or financial forecast. For a mature production implementation, percentile/rank normalization should be considered so that sales, volume, margin, and growth operate on comparable scales.

### 10.2 Product Decision

```dax
Product Decision =
SWITCH(
    TRUE(),
    [Product Opportunity Score] >= 75,
        "SCALE",
    [Product Opportunity Score] >= 50,
        "INVEST",
    [Product Opportunity Score] >= 25,
        "OPTIMIZE",
    "REVIEW"
)
```
Provides a high-level product action recommendation.

## 17. DAX Design Standards

**17.1 Use measures for aggregation.** Prefer a centralized `Total Sales = SUM('Sales'[Total Sales])` measure instead of repeatedly embedding aggregation logic inside visuals.

**17.2 Use `DIVIDE()`.** Prefer `DIVIDE([Total Operating Profit], [Total Sales], 0)` instead of `[Total Operating Profit] / [Total Sales]` — this prevents divide-by-zero errors.

**17.3 Protect time-intelligence measures.** Previous-period calculations should return `BLANK()` where no valid comparison exists rather than displaying misleading zero growth.

**17.4 Use the Date dimension.** Time-intelligence calculations should reference `'Date'[Date]` rather than `'Sales'[Invoice Date]`. This prevents contiguous-date problems and ensures consistent time filtering.

**17.5 Keep business logic centralized.** Business KPIs (e.g. `Operating Margin %`) should be implemented once as reusable measures and reused throughout the model, not duplicated inside individual visuals.

## 18. Threshold Governance

The following thresholds are currently **analytical assumptions**, not confirmed business targets:

| Threshold | Value |
|---|---|
| High Margin | >= 30% |
| Moderate Margin | >= 15% |
| High Volume | >= 100 units |
| Medium Volume | >= 50 units |

Before deployment, validate against:

- Historical performance
- Product distribution
- Margin distribution
- Management targets
- Category benchmarks
- Business strategy

Where appropriate, percentile-based segmentation should replace fixed thresholds.

## 21. Governance Principle

The purpose of this DAX layer is not simply to produce numbers.

Each measure should answer one of three questions:

1. What is happening?
2. Why does it matter?
3. What should management do next?

The model therefore prioritizes decision usefulness, metric consistency, transparency, and reproducibility over unnecessary KPI volume.

## Production Notes

- Measures and calculated columns are documented together here for readability, but **must remain separate in the Power BI model** (measures live in a dedicated measure table; calculated columns live on `Sales`).
- `Product Opportunity Score` (§10.1) is suitable for the portfolio prototype. Before treating it as a production decision score, replace the raw contribution ratios with **rank/percentile normalization** so no single metric can disproportionately distort the 0–100 score.
